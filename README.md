# LaunchMotion — documentación del proyecto

Documentación inicial para empezar a desarrollar un generador de vídeos promocionales con motion graphics para productos SaaS.

## Archivos

- `PROJECT_SPEC.md`: fuente de verdad de producto y desarrollo: posicionamiento, alcance por fases, funciones, UX, stack, arquitectura, IA, storyboard, Remotion, audio, base de datos, API, seguridad, licencias, monetización, marketing, roadmap y criterios de aceptación.
- `AGENTS.md`: reglas obligatorias para el agente de programación.

## Cómo empezar

1. Copia `PROJECT_SPEC.md` y `AGENTS.md` en la raíz del repositorio.
2. Pide al agente que lea ambos antes de proponer o cambiar arquitectura.
3. Empieza por una composición Remotion con datos fijos, motion graphics y sonido; no construyas autenticación, pagos ni integraciones complejas el primer día.
4. Verifica la licencia aplicable de Remotion para herramientas automatizadas de generación de vídeo antes de publicar el SaaS.
5. Valida la calidad de los ejemplos y la disposición a pagar antes de ampliar funcionalidades.
